# VPN Manager Modern

## Description

A VPN manager with a readable English menu for SSH, OpenVPN and UDP services.

## Required

- Ubuntu 20.04+ or Debian 12+, root access and systemd.

## Install / Update

```bash
curl -fsSL https://raw.githubusercontent.com/sansoe2022/VPN_Manager_Modern/main/Plus | sudo bash
sudo menu
```

## Features

- SSH, Dropbear, OpenVPN, WebSocket/SSL and Squid proxy.
- UDP/Hysteria with shared accounts, port hopping and adjustable idle timeout.
- User management, expiry, connection limits and online monitoring.
- OpenVPN profile download links and encrypted full backup/restore.
- Online/CheckUser APIs, speed test and optional x-ui installation.
